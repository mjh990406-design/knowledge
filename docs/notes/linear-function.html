1.1 일차함수, 기울기를 눈으로 이해하기

핵심 질문직접 바꿔 보기내 말로 정리하기복습 질문

이 페이지는 공부 노트의 형식을 보여 주는 예제입니다. 설명과 SVG 그래프, 직접 조작하는 실험, 복습 질문을 한곳에 담았습니다.

01. 핵심 질문

식 y = ax + b에서 a와 b를 바꾸면, 직선은 어떻게 달라질까?

a는 기울기입니다. x가 1 증가할 때 y가 얼마나 변하는지 나타냅니다. b는 y절편으로, 그래프가 y축과 만나는 점의 y좌표입니다. 일차함수에서는 a ≠ 0입니다. 아래 실험에는 비교를 위해 a = 0인 상수함수도 포함했습니다.

02. 직접 바꿔 보기

기울기를 움직여 회전하는 모습을, 절편을 움직여 위아래로 이동하는 모습을 살펴보세요.

y = 1x + 0

03. 내 말로 정리하기

  • a > 0이면 오른쪽으로 갈수록 올라갑니다.
  • a < 0이면 오른쪽으로 갈수록 내려갑니다.
  • |a|가 커질수록 직선이 더 가파릅니다.
  • a를 고정하고 b를 1 늘리면 직선 전체가 위로 1만큼 이동합니다.

04. 복습 질문

기울기를 0으로 만들면 어떤 모양일까?

y = b인 수평선이 됩니다. x가 달라져도 y가 일정합니다. 이 경우는 일차함수가 아닌 상수함수입니다.

y = −2x + 3은 y축의 어디를 지날까?

x = 0을 대입하면 y = 3입니다. 따라서 (0, 3)을 지납니다.

y = x와 y = x + 2는 왜 평행할까?

기울기가 둘 다 1로 같기 때문입니다. 두 번째 직선은 첫 번째 직선을 위로 2만큼 옮긴 것입니다.
