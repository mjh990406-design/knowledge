DDR5 DIMM의 보조 칩과 전원 변환

SPD Hub, PMIC와 Buck, CKD·RCD·MDB의 역할을 구분합니다.

핵심 질문

SPD Hub, PMIC, CKD, RCD, MDB는 각각 무엇을 담당하며, 모든 DDR5 DIMM에 함께 들어가나요?

자료로 확인한 개념

부품주된 역할구분할 점
SPD Hub모듈 정보를 저장하고 관리용 통신을 지원DRAM의 사용자 데이터 전송 경로와 구분
PMIC모듈에 필요한 전압을 생성·조절여러 전원 회로를 관리하는 IC
CKD클라이언트 모듈의 클록을 재정렬·분배CUDIMM·CSODIMM 등에 사용
RCD서버 모듈의 명령·주소·클록·제어 신호를 버퍼링·재구동RDIMM의 데이터 버퍼와 혼동하지 않음
MDBMRDIMM의 여러 rank 데이터를 다중화MRCD와 함께 사용하는 데이터 경로 부품

RCD는 명령·주소·클록·제어 경로, MDB는 데이터 경로를 담당합니다. MRDIMM에는 다중화 동작을 지원하는 MRCD가 사용됩니다. 따라서 CKD/RCD/MDB를 모든 DDR5 DIMM에 공통으로 들어가는 한 묶음으로 보면 안 됩니다. Rambus 서버 칩셋, Rambus DIMM 구성 설명

SPD Hub

SPD는 Serial Presence Detect의 약자입니다. 시스템이 모듈의 특성을 파악하는 데 필요한 정보를 저장·전달합니다. 예를 들어 Renesas SPD5118은 1,024바이트 EEPROM과 Hub 기능, I²C/I³C 통신 인터페이스를 제공합니다. 온도 센서 유무와 지원 기능은 정확한 부품을 확인해야 합니다. Renesas SPD5118

SPD 정보를 읽는 관리 통신과 DRAM 데이터를 읽고 쓰는 고속 메모리 통신은 목적이 다릅니다.

PMIC와 Buck Converter

PMIC는 Power Management IC, Buck Converter는 입력보다 낮은 전압을 만드는 스위칭 전원 회로입니다. PMIC 안에는 여러 Buck 채널과 LDO 등이 포함될 수 있습니다. 예를 들어 Renesas P8900은 강압 스위칭 레귤레이터 4개와 LDO 3개를 제공합니다. 이 개수를 모든 DDR5 PMIC에 적용하면 안 됩니다. Renesas P8900

Buck의 기본 동작은 다음과 같습니다.

  1. 상측 스위치가 켜지면 인덕터 양단 전압에 의해 전류가 증가합니다.
  2. 상측 스위치가 꺼지면 하측 스위치 또는 다이오드 경로로 전류가 이어지며 감소합니다.
  3. 출력 커패시터는 전류 리플을 받아 출력 전압 변동을 줄입니다.

이상적인 정상상태·연속전도모드(CCM)에서는 인덕터의 한 주기 평균 전압이 0이므로 다음 관계를 얻습니다.

D × (Vin − Vout) + (1 − D) × (−Vout) = 0
Vout = D × Vin
D = 상측 스위치 ON 시간 / 스위칭 주기

이 식은 손실을 무시한 근사입니다. 불연속전도모드, 과도 응답, 실제 소자의 전압 강하까지 같은 식으로 단정하지 않습니다. Analog Devices: Buck Power Stage Design Equations

CKD, RCD, MDB

CKD(Client Clock Driver)는 프로세서에서 온 클록을 재정렬하고 DRAM에 분배합니다. CUDIMM·CSODIMM용 칩셋은 CKD, PMIC, SPD Hub로 구성될 수 있습니다. CKD의 존재를 일반 UDIMM 전체에 확대 적용하지 않습니다. Rambus 클라이언트 칩셋

RCD(Registering Clock Driver)는 명령·주소·클록·제어 신호를 다룹니다. MDB(Multiplexed Data Buffer)는 MRDIMM에서 여러 rank의 데이터를 다중화합니다. 이때 MRCD(Multiplexed Registering Clock Driver)가 다중화에 필요한 제어를 지원합니다. Rambus DIMM 구성 설명

제품별로 확인해야 할 사항

  • DIMM 종류와 부품 번호가 없으므로 특정 모듈의 실제 구성은 확인하지 않았습니다.
  • PMIC 입력·출력 전압, 채널 수, 보호 기능은 해당 부품 데이터시트로 확인합니다.
  • CKD 동작 모드와 지원 속도는 부품 세대 및 플랫폼에 따라 확인합니다.
  • 여기서는 MDB를 MRDIMM 문맥으로 해석했습니다. 원래 학습 자료의 약어 정의가 다르면 수정해야 합니다.

내 말로 요약

SPD Hub는 모듈 정보와 관리 통신, PMIC는 전원, CKD/RCD는 클록 또는 명령·주소·제어, MDB는 다중화된 데이터를 담당합니다. PMIC와 Buck은 같은 단어가 아니라 IC 전체와 전압 변환 회로의 관계입니다.
