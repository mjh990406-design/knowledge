# knowledge

글, 이미지, SVG, 인터랙티브 HTML로 쌓는 개인 공부 기록입니다.

## 사이트

- GitHub Pages 주소: https://mjh990406-design.github.io/knowledge/
- 게시 폴더: `docs/`
- 첫 화면: `docs/index.html`
- 예제: `docs/notes/linear-function.html` (직접 만든 일차함수 시각화)

## 기록 추가

1. `docs/notes/`에 주제별 HTML 파일을 만듭니다. 기존 예제를 복사하면 같은 디자인을 사용할 수 있습니다.
2. 이미지와 SVG 파일은 `docs/assets/`에 넣고 상대 경로로 연결합니다.
3. `docs/assets/app.js` 맨 위 `notes` 배열에 제목, 분야, 태그, 요약, 파일 경로를 추가합니다.
4. GitHub에 올리면 Pages에 반영됩니다.

분야는 수학, 컴퓨터, 과학, 인문·사회, 기타로 시작하며 필요에 따라 첫 화면의 필터와 함께 확장합니다. 태그는 주제 사이의 연결을 표현합니다.

각 기록은 핵심 질문 → 개념 설명·시각화 → 내 말로 요약 → 복습 질문 → 참고 자료 순서를 권장합니다. 현재 등록된 기록 1개는 형식 설명용 예제입니다.

## Pages 설정

Settings → Pages → Deploy from a branch → main /docs → Save.

별도 설치나 빌드 과정 없이 HTML 파일을 게시합니다. `docs/index.html`을 직접 브라우저로 열어 로컬에서도 볼 수 있습니다.

공개 저장소와 사이트에 올리는 파일은 누구나 볼 수 있으므로 개인 정보와 공개할 수 없는 원문 자료는 포함하지 않습니다.
